We built FieldSaarthi AI: a voice-to-action workspace for maintenance teams.

A worker reports a fault in Hindi/Hinglish. Gnani Prisma turns the actual audio into a transcript. After human review, FieldSaarthi creates a persistent work order, and a supervisor assigns, progresses and resolves it with an inspectable history. Gnani Timbre can speak a saved-ticket acknowledgment.

We focused on the parts a real workflow needs: clear corrections, known equipment/location validation, duplicate protection, role-based access and truthful model provenance. The attached video demonstrates the actual build using synthetic operational data.
