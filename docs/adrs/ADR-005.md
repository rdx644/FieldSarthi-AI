# ADR-005: Verified Prisma v2.5 baseline

Status: Accepted implementation decision, recorded retrospectively on 2026-11-09 from merged code and the roadmap; remaining gaps are not approved away.

## Context
The genuine baseline must have actual model/request provenance and known account access.

## Decision
Keep the adapter fixed to Prisma v2.5 and one explicitly selected locale. No production fixtures.

## Alternatives considered
Prisma v3 or automatic/code-mix parameters require separate live entitlement and evaluation.

## Consequences
Missing model/request ID is rejected conservatively rather than synthesized. This is stricter than the roadmap suggestion to tolerate absent optional metadata. Hindi evidence does not validate English/Tamil quality.
