# ADR-002: Typed FastAPI REST backend

Status: Accepted implementation decision, recorded retrospectively on 2026-11-09 from merged code and the roadmap; remaining gaps are not approved away.

## Context
The backend must own secrets, audio conversion and validated workflow commands.

## Decision
Use FastAPI, Pydantic v2, SQLAlchemy and HTTPX with strict mypy/Ruff.

## Alternatives considered
Browser-side provider calls expose secrets; a frontend-only prototype cannot provide durable authority.

## Consequences
Endpoint request schemas are typed. Some response dicts remain permissive; the generated OpenAPI is not a fully typed response contract.
