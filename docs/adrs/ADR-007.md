# ADR-007: Timbre after work-order commit

Status: Accepted implementation decision, recorded retrospectively on 2026-11-09 from merged code and the roadmap; remaining gaps are not approved away.

## Context
An optional speech provider outage must not undo the business outcome.

## Decision
Generate optional Hindi Timbre acknowledgment only for a saved, authorized work order via a separate request.

## Alternatives considered
TTS inside the order transaction couples durable success to external availability.

## Consequences
Validate actual binary PCM/WAV and repair streaming length headers. Preserve text success on outage; distinguish requested model from metadata the provider actually returned.
