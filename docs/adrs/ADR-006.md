# ADR-006: Deterministic catalog suggestions and human review

Status: Accepted implementation decision, recorded retrospectively on 2026-11-09 from merged code and the roadmap; remaining gaps are not approved away.

## Context
ASR text does not establish authoritative asset IDs, location, issue or urgency.

## Decision
Match Unicode-normalized aliases against seeded active catalog records; require explicit confirmation and validate final selections server-side.

## Alternatives considered
Unconstrained LLM/autonomous dispatch would add unverified facts and is outside the core.

## Consequences
Original transcript stays immutable; corrections are separate. Current matched aliases are not exact source spans and parser_version is absent: these remain audit gaps, not silently accepted equivalence.
