# ADR-001: React, Vite and TypeScript

Status: Accepted implementation decision, recorded retrospectively on 2026-11-09 from merged code and the roadmap; remaining gaps are not approved away.

## Context
The short deadline needs a typed, responsive web UI with a reproducible build.

## Decision
Use the existing React/Vite/TypeScript client, served by FastAPI at one origin.

## Alternatives considered
A separate static origin adds cookie/CORS deployment complexity; native mobile is out of scope.

## Consequences
The custom hash router and fetch/state hooks replace proposed React Router/Query. Frontend type/build/lint and browser checks are required.
