# ADR-004: Short REST audio with bounded decoding

Status: Accepted implementation decision, recorded retrospectively on 2026-11-09 from merged code and the roadmap; remaining gaps are not approved away.

## Context
Browser MediaRecorder often emits WebM/Opus, while the provider accepts supported short media.

## Decision
Target 25-second recordings and normalize server-side to mono 16 kHz PCM WAV; reject over 30 seconds by actual decoded sample count.

## Alternatives considered
Streaming is out of scope. Declared MIME, extension or duration is not sufficient validation.

## Consequences
The bundled imageio FFmpeg executable performs bounded decoding; a separate ffprobe is unnecessary. Protocol/deadline/concurrency/output bounds and cleanup remain mandatory.
